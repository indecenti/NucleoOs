# Shell cache log — web/shell/sw.js

Why this file exists: every reason the service-worker cache version was rolled used to live in a
**single 10.5 KB comment on line 3 of `sw.js`** — nearly half the file, unreadable in any diff and
shipped to every browser on every update check. The version constant stays in the code; the history
lives here.

**Rolling the cache**: bump `CACHE` in `web/shell/sw.js`, then add a row at the top of this table.
Roll it whenever a precached shell asset changes (JS/CSS/HTML/i18n) or the app registry must be re-read.
