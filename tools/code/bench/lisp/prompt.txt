Write lisp.js: a small Lisp interpreter for the device. It must define a global function lisp(source) that reads one or more expressions and returns the value of the last one.
Support: integers and decimals, symbols, lists in parentheses, comments starting with ; until end of line; the special forms (define name value), (define (name args...) body...), (lambda (args...) body...), (if test then else), (begin ...), (quote x) and 'x; the builtins + - * / (any number of arguments), < > = <=, not, list, car, cdr, cons, null?, length. Functions are closures with lexical scope and recursion works. Falsy values are #f and the empty list. An unbound symbol, a wrong number of arguments or unbalanced parentheses throws an Error with a clear message.
Keep memory low (the engine has tens of KB): no deep copies. Write self-tests at the bottom (factorial of 10, fibonacci, closures, list functions, errors), run the file and fix it until every test passes.
