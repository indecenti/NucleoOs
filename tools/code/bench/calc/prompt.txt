Write calc.js: an arithmetic expression evaluator for the device. It must define a global function evaluate(expr) that takes a string and returns its number value. Support + - * / and ^ (power, right-associative), parentheses, unary minus, decimal numbers and spaces. Use the usual precedence: ^ binds tighter than * and /, which bind tighter than + and -; all are left-associative except ^. Unary minus applies to the factor that follows it (so 2*-3 = -6 and -(2+3)*2 = -10). Invalid input (empty string, unknown characters, unbalanced parentheses, a missing operand, two numbers in a row) must throw an Error with a clear message. Write it as a real tokenizer plus a recursive-descent parser, not with eval. Include self-tests at the bottom that print PASS/FAIL per case and a final summary, run the file and fix it until every test passes.
