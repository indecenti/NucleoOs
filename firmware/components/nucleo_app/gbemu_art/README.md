# Console pictures for the emulators (present and coming)

The gallery's pictures (`gb`, `gbc`, `gg`, `sms`, and for the emulators being prepared `pce`, `nes`, `c64`) and the consoles' small marks drawn wherever their
name would be written (`*_s.png`). Built by `tools/gen-emu-art.py` into `../gbemu_art.h` (RGB565, deflated; the
modules inflate them with the ROM's tinfl).
