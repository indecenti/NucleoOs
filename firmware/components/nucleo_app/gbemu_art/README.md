# Console pictures for the emulators' gallery

Shown on the second screen's gallery of Game Boy (`gb.png`) and Game Gear / Master System (`gg.png`, `sms.png`).
Built by `tools/gen-emu-art.py` into `../gbemu_art.h` (RGB565, deflated; the module inflates them with the ROM's tinfl).

Source photos, all by Evan-Amos, released into the **public domain** (Wikimedia Commons):

- https://commons.wikimedia.org/wiki/File:Game-Boy-FL.jpg
- https://commons.wikimedia.org/wiki/File:Game-Gear-Handheld.jpg
- https://commons.wikimedia.org/wiki/File:Sega-Master-System-Console-FL.jpg
