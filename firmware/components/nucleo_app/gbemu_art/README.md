# Console pictures for the emulators

The gallery's pictures (`gb.png`, `gbc.png`, `gg.png`, `sms.png`) and the consoles' small marks drawn wherever their
name would be written (`*_s.png`). Built by `tools/gen-emu-art.py` into `../gbemu_art.h` (RGB565, deflated; the
modules inflate them with the ROM's tinfl).

Source photos, all by Evan-Amos, released into the **public domain** (Wikimedia Commons):

- https://commons.wikimedia.org/wiki/File:Game-Boy-FL.jpg
- https://commons.wikimedia.org/wiki/File:Nintendo-Game-Boy-Color-FL.jpg
- https://commons.wikimedia.org/wiki/File:Game-Gear-Handheld.jpg
- https://commons.wikimedia.org/wiki/File:Sega-Master-System-Console-FL.jpg
